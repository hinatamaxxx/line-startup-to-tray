## 初回の一般向けプレビュー配布

Windowsへのサインイン時に、LINEの画面を出さずに通知領域へ起動する非公式ツールです。

### ダウンロードするもの

**Assetsの `LineTrayStartup-Setup-0.2.0-preview.1.exe` をダウンロードしてください。**
`Source code (zip)` や `Source code (tar.gz)` は開発者向けです。

### セットアップ

1. LINEの自動ログインをONにし、通知領域のメニューからLINEを「終了」します。
2. ダウンロードしたEXEを開き、「セットアップ」を押します。
3. 「LINEを起動」で試し、アイコンのダブルクリックで開けることを確認します。

管理者権限、コマンド入力、追加のダウンロードは不要です。以後は、Windowsにサインインすると自動で通知領域へ起動するようになります。

### この版で確認したこと

Windows 11 Home 23H2 x64・LINE 26.4.2.3957で、起動画面とメイン画面を表示しない起動、アイコンからの再表示、ログイン維持を確認しました。導入と設定復元も独立したテスト領域で確認しています。

**PC再起動を伴う最終確認は未実施のため、プレビュー版として配布します。** LINEの更新で動作しなくなる場合や、通知領域アイコンの未読バッジが反映されない場合があります。

コード署名はありません。照合用の `SHA256SUMS.txt` を添付しています（通常の利用ではダウンロード不要です）。LINE本体やログイン情報は同梱していません。
