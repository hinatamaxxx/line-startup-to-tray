## セットアップがWindows本体へ適用されない問題を修正

- 一部のツールから導入した際、設定とファイルがツール専用の隔離領域へ保存され、再起動時には元のLINEが起動する原因を確認しました。
- セットアップを通常のWindowsプロセスとして起動し直し、実際のLocalAppDataへファイルを配置するようにしました。
- 自動起動の登録・復元・セットアップ状態の確認に、Windowsの実際のユーザーレジストリを使うようにしました。変更後の値も読み返します。
- このPCで、Windows側から補助EXEとDLLの実ファイルが見えることと、実際の `LINE` 起動項目が補助EXEを指していることを確認しました。

ウィンドウを定期的に探す監視ループや、起動後に画面を閉じるための遅延処理は追加していません。

Windowsへのサインイン時に、LINEの画面を出さずに通知領域へ起動する非公式ツールです。

### ダウンロードするもの

**Assetsの `WindowsLineStartToTray-Setup-0.2.0-preview.5.exe` をダウンロードしてください。**
`Source code (zip)` や `Source code (tar.gz)` は開発者向けです。

### セットアップ

1. LINEの自動ログインをONにし、通知領域のメニューからLINEを「終了」します。
2. ダウンロードしたEXEを開き、「セットアップ」を押します。
3. 「LINEを起動」ボタンを押して、アイコンのダブルクリックで開けることを確認します。

管理者権限、コマンド入力、追加のダウンロードは不要です。セットアップすると、Windowsサインイン時に本ツールからLINEを起動する設定が登録されます。

### この版で確認したこと

Windows 11 Home 23H2 x64・Microsoft StoreからインストールしたLINE 26.4.2.3957の環境で、実際の保存先への配置と起動設定の適用を確認しました。通常プロセスへの起動し直し、実レジストリの読み書き、旧版からの移行、設定の復元、セットアップ画面のテストも通っています。LINEの表示とアイコンを処理するネイティブコードは前版と同じものです。

**修正後のPC再起動を伴う最終確認は未実施のため、プレビュー版として配布します。** Windowsのスタートアップでは `LINE` をONにしてください。LINEの更新で動作しなくなる場合や、通知領域アイコンの未読バッジが反映されない場合があります。

コード署名はありません。照合用の `SHA256SUMS.txt` を添付しています（通常の利用ではダウンロード不要です）。LINE本体やログイン情報は同梱していません。
