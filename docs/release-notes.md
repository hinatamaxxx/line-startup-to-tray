## 再起動時の起動経路を見直し

- 旧方式でPC再起動後のLINEに補助DLLが読み込まれず、画面の非表示とアイコンの変更が適用されない問題を確認しました。
- Windowsの元の `LINE` スタートアップ項目の起動先を本ツールへ切り替えます。別項目 `LineTrayStartup` は削除し、起動経路を1つにします。
- LINEランチャーの作業ディレクトリを明示し、Windowsサインイン時の作業ディレクトリに依存しないようにしました。
- 起動用EXEにもUTC日時付きの診断ログを追加し、起動用EXEの実行と補助DLLの読み込みを分けて確認できるようにしました。
- 設定を元に戻すと、LINE本来の起動コマンドと有効・無効の状態を復元します。旧版の導入前バックアップも引き継ぎます。

ウィンドウを定期的に探す監視ループや、起動後に画面を閉じるための遅延処理は追加していません。

Windowsへのサインイン時に、LINEの画面を出さずに通知領域へ起動する非公式ツールです。

### ダウンロードするもの

**Assetsの `WindowsLineStartToTray-Setup-0.2.0-preview.4.exe` をダウンロードしてください。**
`Source code (zip)` や `Source code (tar.gz)` は開発者向けです。

### セットアップ

1. LINEの自動ログインをONにし、通知領域のメニューからLINEを「終了」します。
2. ダウンロードしたEXEを開き、「セットアップ」を押します。
3. 「LINEを起動」ボタンを押して、アイコンのダブルクリックで開けることを確認します。

管理者権限、コマンド入力、追加のダウンロードは不要です。セットアップすると、Windowsサインイン時に本ツールからLINEを起動する設定が登録されます。

### この版で確認したこと

Windows 11 Home 23H2 x64・Microsoft StoreからインストールしたLINE 26.4.2.3957で、手動起動時の表示抑制とアイコン登録を確認しています。導入、起動経路の統一、旧版からの移行、設定と起動コマンドの復元は独立したテスト領域で確認しました。

**修正後のPC再起動を伴う最終確認は未実施のため、プレビュー版として配布します。** Windowsのスタートアップでは `LINE` をONにしてください。LINEの更新で動作しなくなる場合や、通知領域アイコンの未読バッジが反映されない場合があります。

コード署名はありません。照合用の `SHA256SUMS.txt` を添付しています（通常の利用ではダウンロード不要です）。LINE本体やログイン情報は同梱していません。
